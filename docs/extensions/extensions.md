## Pi extensions

| # | Extension | Description |
|---:|---|---|
| 1 | [pi-provider-litellm](./pi-provider-litellm.md) | Fetches LiteLLM model metadata, such as context size and pricing. |
| 2 | [pi-mcp-adapter](./pi-mcp-adapter.md) | Bridges pi with MCP-compatible tools and servers. |
| 3 | [pi-hashline-readmap](./pi-hashline-readmap.md) | Replaces Pi’s native read/edit tools with hashline-based ones for safer edits, file maps, symbol reads, AST search, and a few other useful upgrades. |
| 4 | [@narumitw/pi-usage](./pi-usage.md) | Shows current-account usage for Codex, OpenRouter, OpenCode Go, and other supported providers inside Pi. |
| 5 | [pi-subagents](./pi-subagents.md) | Gives Pi focused helper agents to review code, scout files, plan changes, implement tasks, or run work in parallel. |
| 6 | [@plannotator/pi-extension](./plannotator-pi-extension.md) | Adds browser-based plan approval, markdown annotation, and code review feedback workflows to Pi. |
| 7 | [@juicesharp/rpiv-ask-user-question](./rpiv-ask-user-question.md) | Adds a structured questionnaire dialog so Pi can ask clarifying questions with typed options, previews, and multi-select choices. |
| 8 | [@juicesharp/rpiv-btw](./rpiv-btw.md) | Adds `/btw <question>` for context-aware side questions without adding answers to the main conversation context. |
| 9 | [@juicesharp/rpiv-args](./rpiv-args.md) | Adds shell-style `$1`, `$ARGUMENTS`, runtime variables, and inline shell substitutions for Pi skills. |
| 10 | [pi-web-access](./pi-web-access.md) | Adds web search and content extraction to Pi. |
| 11 | [pi-powerline](./pi-powerline.md) | Improves Pi's terminal UI with a Powerline-style header, footer, and breadcrumb. |
| 12 | [pi-skillful](./pi-skillful.md) | Allows skills to be invoked anywhere in a prompt, selected skills to be hidden to reduce prompt context, and skill visibility to be toggled directly in a session. |
| 13 | [@dietrichgebert/ponytail](./ponytail.md) | Keeps coding changes minimal by preferring reuse, standard libraries, and native platform features. |
| 14 | [preset](./preset.md) | Switches the active Pi tool surface between the `nano`, `standard`, and `agents` presets. |
| 15 | [@luxusai/pi-hindsight](./pi-hindsight.md) | Adds persistent project memory to Pi using a Hindsight server. |
| 16 | [pi-context-view](./pi-context-view.md) | Visualizes context usage and exposes hidden system prompt, tool definitions, and extension injections. |
| 17 | [plannotator-control](./plannotator-control.md) | Local enter/status adapter for Plannotator plan mode. |
