## Pi extensions

| # | Extension | Description |
|---:|---|---|
| 1 | [pi-provider-litellm](./pi-provider-litellm.md) | Fetches LiteLLM model metadata, such as context size and pricing. |
| 2 | [pi-mcp-adapter](./pi-mcp-adapter.md) | Bridges pi with MCP-compatible tools and servers. |
| 3 | [context-mode](./context-mode.md) | Keeps large outputs out (=saving the tokens) of chat context by adding sandboxed analysis, searchable stored knowledge, and automatic hook-based routing in Pi. |
| 4 | [pi-hashline-readmap](./pi-hashline-readmap.md) | Replaces Pi’s native read/edit tools with hashline-based ones for safer edits, file maps, symbol reads, AST search, and a few other useful upgrades. |
| 5 | [@narumitw/pi-codex-usage](./pi-codex-usage.md) | Shows ChatGPT Codex subscription usage inside Pi. |
| 6 | [pi-subagents](./pi-subagents.md) | Gives Pi focused helper agents to review code, scout files, plan changes, implement tasks, or run work in parallel. |
| 7 | [@plannotator/pi-extension](./plannotator-pi-extension.md) | Adds browser-based plan approval, markdown annotation, and code review feedback workflows to Pi. |
| 8 | [@juicesharp/rpiv-ask-user-question](./rpiv-ask-user-question.md) | Adds a structured questionnaire dialog so Pi can ask clarifying questions with typed options, previews, and multi-select choices. |
