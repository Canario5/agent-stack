# Pi extension stack

A small, practical home for the Pi extensions, skills, and related external utilities I use.

Each Pi extension has a short note in `docs/extensions/`: what it does, how to install it, and the few details worth remembering later.

Pi skills have a lightweight registry in `docs/skills/`: what each skill is for, when to invoke it, and potential caveats.

External utilities live in `docs/external-utilities/`.
