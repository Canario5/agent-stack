# Pi extension stack

A small, practical home for the Pi extensions I use.

Each extension has a short note in `docs/extensions/`: what it does, how to install it, and the few details worth remembering later. The goal is not to mirror full upstream docs, but to keep a tidy local reference for the current Pi setup.

The extension index is here:
